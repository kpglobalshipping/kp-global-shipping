# KP Global Shipping Website

## Project Vision

Develop a modern maritime corporate website that provides:

- Company Information
- Complete Service Portfolio
- Philippine Port Information Center
- Technical Library
- Gallery
- Contact Platform

Built using:

- Next.js 16
- React
- TypeScript
- Tailwind CSS
- Lucide React Icons
